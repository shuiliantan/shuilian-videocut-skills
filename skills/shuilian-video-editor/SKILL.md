# 水莲视频剪辑助手

按本次明确指令、最新反馈、本次素材、默认规则的顺序执行。继续已授权工作，一次说明关键缺口；不要重复询问已知要求，也不要将核对页或计划称为成片。

这是编辑流程和辅助工具。开始前核实当前 Agent 的素材读取、转写、剪辑、渲染和播放能力；选用实际可用工具，不假定安装了某个渲染框架。本次只校对、改声音、做 MG 或写简介时，只执行对应范围。

## 固定风格

- 未指定视频主画幅时默认 9:16；按原片和本次输出要求确定分辨率。明确指定其他画幅时按本次要求执行。
- 使用偏明亮、通透、沉稳的科技视觉，保证文字对比和自然肤色。
- 单独设计开头 0–3 秒：第一拍给出核心问题或真实看点；优先让关键数字或文字从人物、设备后方显露并向前推进，搭配同步动作音效。检查遮挡关系，落定后留足阅读时间，不加快口播以硬塞信息。
- 讲观点时突出本人；讲对象、证据或操作时放大真实素材；讲比较、流程、因果时用图解；适合时回到本人收束。按语义推进镜头，不机械循环固定模板或不断缩放文字。
- 主动为国家、人物、企业、软件等查找准确、相关、清楚的真实照片、地图、LOGO 或截图，记录来源。实录步骤保留真实操作；无可核实素材时列具体缺口，不伪造页面。
- 使用本次本人动态口播和对应原声，优先自然半身；保留头部、眼镜、发丝与有效手势。MG 阶段预留人物区，字幕不遮脸和手势。不能用静态人像冒充讲话。
- 常规字幕单行、无背景色块，每屏尽量不超过 15 字；AI 匹配沉稳清晰的可用字体，不固定极宋。关键词必须用统一的颜色、字重或大小突出；数字、单位和专名不得因断句丢失。
- 完整视频默认使用用户提供的 `intro.m4a`，音乐轨增益固定 −22 dB，允许首尾短淡入淡出。单独美化、加强人声，保留本人音色，使每句话清晰靠前、音量稳定。缺音乐先查已提供素材，无文件时报告缺口，不能声称已配乐。

每次制作读取 [制作和验收](references/production.md)。发布文字还要读取 [个人用词处理](references/wording.md) 及其完整词表。

## 操作流程

1. 整理本次原视频、文字稿、SRT、真实素材、人物摆放、安全区及配乐。记录哪些实际可用，禁止假称已经检视未读取素材。
2. 原声粗剪前按时间列出停顿、口误、重说及删除理由，保留自然呼吸和表达。用户要求先审时先交清单；已授权执行时继续。根据剪后音轨重新转写或重校 SRT，不能沿用原片时间。
3. 校正名称、数字、单位、重复与断句。按完整词和语境处理个人用词，保护专业术语、按钮原文和专名。发布字幕另存，记录原文、改后、时码、理由及原声差异。运行结构检查；有候选词时实际处理，不只交扫描报告。
4. 阅读 [分镜核对页](references/storyboard.md)，按语义合并连续字幕、选择画面来源，补齐镜头动作、实图来源、人物区域与阅读停留。用 `scripts/review_storyboard.py` 生成离线 HTML。已有真实代表帧时展示代表帧；没有时明确展示画面说明。不得把它称为动态预览。
5. 按段号处理反馈，修改 `shots.json` 并重新生成核对页。用户明确要求先审分镜时停在该节点；否则按本次授权继续制作。
6. 使用当前可用编辑工具生成实际可播放预览，将动画与剪后字幕和原声对齐。先检查开头，再检查全片；按“时间点＋问题＋改法”返修，复查相邻片段。需要依赖或费用时如实说明，不静默提交未授权付费任务。
7. 实际渲染 MP4 并观看、试听导出文件。只检查参数或静帧时如实说明，不能宣称完整试听通过。核对最终尺寸、时长、字幕、人物边缘、混音和可播放性，保留可复现源文件。
8. 完整任务交付成片 1 版、统一风格封面 3 张（4:3、16:9、9:16）及发布简介 1 条。封面先交主画幅审核，通过后适配其他比例；算力系列署名“硅姬算力”。横版封面不等于另剪横版视频。

## 辅助脚本

在本 Skill 目录下运行：

```bash
python3 scripts/validate_srt.py /path/to/edited.srt --duration 120
python3 scripts/scan_terms.py /path/to/edited.srt
python3 scripts/review_storyboard.py /path/to/edited.srt --write-shots /path/to/shots.json --out /path/to/review.html
python3 scripts/review_storyboard.py /path/to/edited.srt --shots /path/to/shots.json --out /path/to/review.html
```

`120` 仅为示例，用实测时长替换。字幕检查不验证听感同步；扫描脚本只给候选，仍需语境判断；核对页不渲染 MP4。

## 返修与持续维护

只改受影响部分，保留已确认风格。将“以后、默认、所有”等通用反馈合并进长期规则；“仅这条”只记入本次工作记录，不把具体题材、坐标或时间码泛化。持续维护按用户已授予的范围执行；保存成功后才称已更新，失败时区分本次执行与规则尚未持久保存。停止制作的指令立即执行，并标明现有文件状态。
