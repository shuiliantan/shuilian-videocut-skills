# 制作和验收

## 画面

先建立主视觉，再确定镜头运动。推进用于突出对象或数字，横移用于比较，跟随用于演示过程，拉回用于呈现整体关系；每次动作应能解释其信息目的。动作落定后保留阅读时间。

开头用纵深、遮挡和同步声音建立冲击力。可用关键数字从人物背后升起、设备后露出核心问题等结构，避免无关闪烁。不要承诺留存、点赞或传播结果。

实操段按讲解、全屏操作、结果展示、人物收尾安排适用镜头。保留用户指定的原片步骤，压缩等待时明确跳过，不伪造操作成功。真实图片在手机端也应能辨识；截图保持真实内容，标注不能遮住按钮和结果。记录来源页面与检索日期，不虚构来源。

本人动态口播与原声同步。自然半身优先，头顶、眼镜、手势完整；检查发丝白边、光晕、透明边缘和连续帧闪动。前景与人物遮挡正确，不能用截图冒充口播动态。MG 阶段先留人物和字幕空间。

## 字幕和声音

字幕单行、无底色块，正常播放时每句话跟随原声；关键词样式统一，最多突出当前少量核心信息。大字只承担标题、对象或数据强调，避免两套长字幕争抢注意力。可用已安装、授权适合的现代黑体等沉稳字体，查看中文、数字、英文字母和符号是否缺字，不指定极宋。

人声按原录音选择均衡、动态控制、齿音及峰值处理，前后音量可比地试听。音乐轨使用用户自己的 Intro，增益固定 −22 dB；这是轨道增益，不是整片响度或人声音量。人声、BGM、动作音效分轨，不改变音乐增益来代替人声处理。逐一试听人声最轻、音乐最响、音效叠加处，再试听全片。不得仅凭技术参数报告听感合格。

用户明确无 BGM、换曲目或指定其他音量时按本次要求执行。音乐缺失可继续不依赖音乐的制作，不能宣称已经找到或下载。

## 交付检查

- 根据实际剪后音轨核对字幕和动画时码，数字、单位、专名和否定完整。
- 开头 0–3 秒有真实看点、纵深动画与清晰落点；全片偏明亮且文字对比充分。
- 每段素材正确、来源可追溯、阅读时间足够；真实操作没有被说明图误换。
- 人物、字幕和关键截图始终在安全区，不遮脸、手势和结果；实际播放检查人物边缘与声画同步。
- 人声清晰稳定，BGM 保持指定增益，无爆音和突断；实际完整试听。
- 最终文件可播放，画幅和总时长正确，源文件能复现；技术检查和实际观看的状态分别记录。
- 封面先审主画幅，再分别构图适配；算力系列署名“硅姬算力”，其他题材沿用用户指定署名，不推断账号改名。
- 简介用第一人称讲实际做了什么、怎样做、有什么可复用的经验；可标“爆款简介”，但不保证传播结果。不借用他人的数据或经历。
